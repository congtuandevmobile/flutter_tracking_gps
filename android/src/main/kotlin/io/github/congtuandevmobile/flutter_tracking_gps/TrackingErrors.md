# TrackingErrors.kt

**Path:** `android/src/main/kotlin/io/github/congtuandevmobile/flutter_tracking_gps/TrackingErrors.kt` · **Layer:** Android native (error handling)

## Purpose
Implements the project rule "never swallow an error": every native failure becomes a `FlutterError` with a stable **code**, a short **message** and **details** (the stack trace), and is also logged.

## Members
| Member | Description |
|---|---|
| `TrackingErrorCode` (object) | String constants Dart can switch on: `NO_ACTIVITY`, `PERMISSION_REQUEST_FAILED`, `PERMISSION_REQUEST_PENDING`, `START_FAILED`, `PAUSE_FAILED`, `RESUME_FAILED`, `STOP_FAILED`, `RESTORE_FAILED`, `CORE_REJECTED`, `STORE_READ_FAILED`, `STORE_CLEAR_FAILED`, `LOCATION_UPDATES_FAILED`, `STORE_WRITE_FAILED`. |
| `Throwable.toFlutterError(code, message)` | Logs with `Log.e` and returns `FlutterError(code, "message (ExceptionType: cause)", stackTrace)`. |
| `flutterError(code, message, details = null)` | Same for failures the code detects itself (no underlying exception). |

## Notes
`internal` to the plugin module. `FlutterError` is the class generated by Pigeon (`TrackingApi.g.kt`).

## Used by
`FlutterTrackingGpsPlugin.kt`, `TrackingEngine.kt`.
