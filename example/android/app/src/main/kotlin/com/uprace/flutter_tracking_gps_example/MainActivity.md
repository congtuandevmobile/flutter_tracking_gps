# MainActivity.kt

**Path:** `example/android/app/src/main/kotlin/com/uprace/flutter_tracking_gps_example/MainActivity.kt` · **Layer:** example app (Android, template file)

## Purpose
The standard Flutter host activity of the example app. It adds no logic: `class MainActivity : FlutterActivity()` lets Flutter draw the UI and registers the plugins (including `flutter_tracking_gps`).

## Notes
Generated by `flutter create`; the plugin gets its `ActivityAware` callbacks from this activity, which is how `requestPermission` can show the system dialog.
